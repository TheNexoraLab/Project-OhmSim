# OhmSim Handbook

Place the approved OhmSim Product Design & Development Handbook PDF in this folder for the development team’s reference.

Recommended filename:

```text
OhmSim Product Design & Development Handbook.pdf
```

The handbook is the product and process reference for this repository. Developers should consult the relevant chapter before implementing a feature and should raise conflicts with the project manager before changing the agreed architecture.

Do not commit drafts, private credentials, or unrelated documents here. If the final PDF is too large or restricted, keep it in the team’s approved document storage and add the official link here instead.
